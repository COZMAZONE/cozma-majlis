# مصادر صوت العميل

STATUS: NOT_BUILT

هذا الملف يحمل كلام العملاء الحقيقي **حرفيًا**، وكل سطر له رقم مصدر ثابت. هو المكان الوحيد في المجلس كله اللي فيه اقتباسات. `scripts/check_quotes.py` يتأكد إن كل اقتباس «...» (S###) في الجلسة موجود هنا حرف بحرف.

## قواعد الكتابة (للرئيس وقت التهيئة)

- انسخ الكلام كما هو، بأخطائه الإملائية ولهجته. لا تصحّح ولا تجمّل ولا تختصر داخل الاقتباس.
- احذف أي اسم أو رقم جوال أو رقم طلب أو عنوان أو بريد، وحط مكانه [محذوف].
- لا تخترع أي سطر. إذا التاجر عطاك 23 تقييم، يكون عندك 23 سطر فقط.
- رقّم بالترتيب S001، S002، ... ولا تعيد استخدام رقم.
- بعد كل سطر: المصدر (تقييم منتج، تقييم متجر، واتساب، تعليق إعلان، شكوى)، التقييم بالنجوم إن وجد، والشهر.
